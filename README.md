# RTG Simulator

RTG Simulator is a football-themed card collection game developed in spring 2025 as part of my second-year Web Programming course at Babeș-Bolyai University.

## About the Project

The application allows users to collect football player cards by opening three different types of packs.

Players can keep the cards they obtain or sell them to earn in-game coins. These coins can then be used to purchase more valuable packs, giving users the opportunity to collect better football players.

The project was developed as a **local educational application**, with a focus on learning full-stack web development.

## Technologies Used

**Frontend**
- React
- TypeScript
- Vite

**Backend**
- Java
- Spring Boot
- REST API
- JDBC

**Database**
- MySQL

## What I Learned

During this project, I gained hands-on experience with:

- Building a frontend application using React.
- Developing REST API endpoints with Spring Boot.
- Connecting a React frontend to a Java backend.
- Working with relational databases using MySQL and JDBC.
- Understanding how frontend, backend, and database components communicate in a full-stack application.
